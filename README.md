# Movie & TV Show Search

A responsive and interactive web application for searching movies and TV shows. The application uses a movie database API to fetch and display entertainment information dynamically.

## Features

* Search for movies and TV shows
* Display movie and series information
* Show posters and images
* Display release dates
* Display ratings
* Show genres and other available information
* Interactive search interface
* Responsive design for different screen sizes
* Dynamic content loaded from an external API

## Technologies

* HTML5
* CSS3
* JavaScript
* REST API

## How It Works

Users can enter the name of a movie or TV show in the search field.

The application sends a request to the movie database API using JavaScript and displays the returned information dynamically on the page.

## Installation

No installation or additional dependencies are required.

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/atiyeh-thd/movie-search-app.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

## API Key

If the API requires an API key, do not upload your private API key directly to a public GitHub repository.

For a production project, store sensitive API credentials securely on a backend server or use an appropriate environment-variable setup.
